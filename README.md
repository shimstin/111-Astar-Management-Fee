# 111호 관리비 정산기 V9

## 변경사항
- 월별 입력값을 완전히 분리했습니다.
  - 7월/8월 등 새로운 달을 선택하면 해당 월 저장값이 없을 경우 빈 입력창으로 시작합니다.
  - 6월 값이 다른 달로 따라오지 않습니다.
  - `입력 초기화`는 현재 선택 월의 입력값만 완전히 비웁니다.
- 면적 관련 관리비는 뉴모모 50% / 29도 50%로 고정했습니다.
  - 6월은 29도 입주일(6/9) 때문에 29도 50% 몫에 22/30 일할 계산을 적용합니다.
  - 7월부터는 두 가게 모두 한 달 전체이므로 정확히 50:50입니다.
- 주차비는 비율 계산을 없애고 각 가게 실제 부담액을 직접 입력합니다.
- 참고 메모: 29도는 6/10~8/3 주차 이용분 지불 예정으로 7월/8월 관리비에도 일부 요금이 추가될 수 있으며, 이후 당분간 주차비를 부담하지 않을 예정입니다.
- 월별 기록 저장/불러오기/복사/삭제 기능은 유지됩니다.
