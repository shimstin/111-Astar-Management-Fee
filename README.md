# 111호 관리비 정산기

뉴모모와 29도의 월별 전기·수도·공동 관리비를 정산하는 단일 페이지 웹 앱입니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 정산 월을 선택하면 전기·수도 검침 기간이 자동으로 표시됩니다. 고지서 총액을 입력합니다.
3. 전기와 수도의 전체 사용량·요금, 29도의 시작·종료 검침값을 입력합니다.
4. 자동 계산된 정산 결과를 확인합니다.
5. **PDF로 저장 · 공유**를 눌러 인쇄 화면에서 **PDF로 저장**을 선택합니다.

## 계산 기준

- 29도 사용량 = 종료 검침값 - 시작 검침값
- 29도 사용 요금 = 전체 요금 × 29도 사용량 ÷ 전체 사용량 (원 단위 반올림)
- 뉴모모 사용량 = 전체 사용량 - 29도 사용량
- 뉴모모 사용 요금 = 전체 요금 - 29도 사용 요금
- 각 점포 공동 관리비 = (당월 부과금액 - 전체 전기요금 - 전체 수도요금) ÷ 2 후 1원 단위 올림
- 각 점포 납부액 = 해당 점포 전기요금 + 수도요금 + 공동 관리비
- 두 점포 납부액의 합은 당월 부과금액과 대조해 화면에 표시됩니다. 공동 관리비가 0.5원으로 나뉘는 달에는 양쪽 모두 올림하므로 합계가 고지액보다 1원 많습니다.

## 배포

별도 설치나 빌드가 필요하지 않습니다. `index.html`을 GitHub Pages, Vercel, Netlify 등의 정적 호스팅에 올리면 됩니다.

Vercel에서는 이 폴더를 업로드하고 Framework Preset을 **Other**, Output Directory를 비워 둔 상태로 배포하세요.

## 참고

- 입력 내용은 서버에 저장되지 않습니다.
- PDF 출력은 A4 세로 1페이지에 맞게 구성되어 있습니다.
- 전체 사용량보다 29도 사용량이 크거나, 고지서 총액보다 전기·수도요금 합계가 크면 입력 확인 안내가 표시됩니다.
