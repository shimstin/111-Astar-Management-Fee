# 111호 관리비 정산기 V8

## 최종 화면 구조
1. 정산 월과 기간 확인
2. 이번 달 관리비 고지서 항목 입력
3. 111호 전체 전기·수도 사용량 입력
4. 29도 시작·종료 계량값 입력
5. 정산 결과 확인 및 기록 저장

## 기본 설정
- 면적 비율
- 주차비와 주차 대수
- 뉴모모·29도 계산기간

위 항목은 `기본 설정 펼치기` 안에 넣어 평소에는 숨겨두었습니다.

## 기록
- 복사·기록 버튼을 누르면 해당 월의 모든 입력값과 계산 근거를 저장합니다.
- 기록에서 당시 값을 다시 불러오거나 복사·삭제할 수 있습니다.
